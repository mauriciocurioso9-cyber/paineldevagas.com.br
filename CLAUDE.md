# RecrutadorIA

Este é o projeto **RecrutadorIA** — plataforma de recrutamento com análise de currículos por IA.

## Escopo
Este contexto é exclusivo do projeto RecrutadorIA. Não misturar com outros projetos (Financeiro, Atlas financeiro da construção).

## Stack
- Frontend: HTML/CSS/JS (SPA)
- Backend: Supabase (banco de dados e autenticação)
- IA: Claude API (Anthropic)
- Deploy: Vercel

## Estrutura
- `index.html` — aplicação principal
- `config.js` — configurações
- `supabase/` — funções e migrações do banco
- `.claude/` — configurações do Claude Code

## Comandos úteis
- Deploy: via Vercel (automático no push para main)
- Banco: gerenciado via Supabase MCP
